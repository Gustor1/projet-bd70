# Lire les diagrammes

Les sources DOT sont éditables ; les SVG et le recueil PDF sont vectoriels. Les diagrammes complets sont des plans de grand format : les lire par zoom à 100 %, puis ouvrir les détails par domaine pour présenter une partie. Ne pas imprimer le schéma complet réduit sur A4.

- cas-utilisation : acteurs et cas UML, héritage des droits, include/extend.
- mcd-* : concepts, attributs métier et associations à cardinalités.
- mld-* : tables physiques, tous les attributs et types, PK/FK, NULL/NN et UNIQUE.
- mld-historisation : tables techniques et liens d’auteur.

Le dictionnaire complète les attributs et unités ; le SQL donne les CHECK. Les liens optionnels et les FK uniques sont distingués dans le MLD. Le MCD inclut des associations N:N matérialisées par des tables dans le MLD.
