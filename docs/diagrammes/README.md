# Schéma relationnel du rendu

[mld-complet.svg](mld-complet.svg) et [le PDF du rendu](../../livrables/schema-relationnel/mld-complet.pdf) représentent les 41 tables du schéma physique courant. Le DOT est la source modifiable. schema.json et labels.json contiennent les métadonnées utilisées par le générateur.

Le schéma indique les colonnes, types, PK, FK, nullabilités et unicités. Les CHECK, procédures et déclencheurs sont définis dans sql/.

Le schéma est vectoriel et de grand format, à lire avec zoom. [L’index des modèles](../modeles-reference.md) donne les références du use case corrigé et du MCD Chen.
