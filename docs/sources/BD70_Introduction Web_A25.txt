Le client envoi une requête au serveur (par exemple GET 
http://www.google.fr
)

PHP
PHP date de 1994 mais reste le langage le plus utilisé pour la programmation d’applications Web (~80% des sites internet)
Langage interprété
Le contenu des pages Web est décrit dans des fichiers .
php
 : le serveur interprète les pages .
php
 pour formuler la réponse aux clients
Le fichier .
php
 est un mélange de contenu statique (écrit en HTML) et de contenu dynamique (écrit en PHP) : le contenu statique est fixe, le contenu dynamique est calculé au moment de la requête (en fonction des paramètres de la requête, en fonction de l'état de la base de données, etc.)

ppt/slides/slide25.xml
Syntaxe PHP
Langage procédural : suite d'instructions
Chaque instruction se termine par un point-virgule
Les variables commencent toujours par le caractère $
Le typage est dynamique : il n'est pas nécessaire de préciser le type des variables (mais c'est recommandé de le faire quand c'est possible)
Les structures alternatives et répétitives usuelles sont disponibles avec la même syntaxe qu'en C : if, while, do … while, switch, for
L'appel d'une fonction se fait comme en C : ma_fonction($param1, $param2);
La plupart des opérateurs sont les mêmes qu'en C :
Affectation avec =
Calculs avec +, -, *, /
Comparaisons avec ==, <=, >=, <, >, !=
Opérations booléennes avec &&, ||
